# Lakshmi & Devender — Royal Burgundy & Gold Invitation

This is the complete responsive wedding invitation website inspired by the approved burgundy-and-gold preview.

## Included
- Royal burgundy, champagne-gold and ivory design
- Full-screen opening cover with Lakshmi & Devender, 13 December 2026 and clickable View Invitation
- AI-generated bride and groom image cropped from the approved preview artwork
- Wedding family details, event schedule, venue image and map link
- RSVP contacts and WhatsApp wishes link
- Floral, lantern, palace and ornamental styling
- Mobile and desktop responsive layouts
- No music, audio player, sound button or audio files

## Run
Open `index.html` in a browser or use VS Code Live Server.

## Deploy on Vercel
1. Upload the whole `lakshmi-devender-royal-burgundy` folder to GitHub.
2. Import the repository into Vercel.
3. Select **Other** as the framework preset.
4. No build command is required. Deploy the project.

Keep the `assets` folder alongside `index.html`, `style.css` and `script.js`.
