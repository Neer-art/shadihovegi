# Lakshmi & Devender — Royal Wedding Invitation

Responsive animated wedding invitation website built with HTML, CSS and vanilla JavaScript.

## Features
- Royal maroon and antique-gold design
- Animated invitation opening screen
- AI-generated bride and groom portrait (`assets/ai-bride-groom.jpg`)
- Countdown to 12 December 2026, 7:00 PM IST
- Wedding events, family details, venue and RSVP/contact links
- Google Maps and WhatsApp links
- Mobile-responsive layout

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy to Vercel
1. Upload the complete folder to GitHub.
2. Import the repository into Vercel.
3. Choose **Other** as the framework preset.
4. Deploy. No build command is required.

## Optional music
Add a royalty-free MP3 named `music.mp3` inside `assets/` to enable the music toggle.
